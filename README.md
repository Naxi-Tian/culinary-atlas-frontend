# Culinary Atlas — Interactive Suite Frontend

Culinary Atlas is a digital archive designed to preserve recipes, oral histories, and food traditions. As a frontend engineer with Duke Product Lab (CFCI), beginning in September 2026, Tenne Tian worked on its Interactive Suite.

The documented work includes reflection-game and survey interfaces, navigation flows, and a personalized Cook's Book experience intended to help users document their food histories.
